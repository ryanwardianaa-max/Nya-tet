# Nya-tet

Catat keuangan secepat bicara. Nya-tet menggunakan AI untuk entri otomatis via suara dan scan nota - tanpa kerumitan input manual.

## Fitur
- Voice AI: Catat pengeluaran hanya dengan berbicara.
- Vision AI: Scan nota otomatis tanpa ketik manual.
- Excel & PDF Export: Laporan cantik yang siap di-print.
- Supabase Auth: Login dengan Google Auth yang aman.
